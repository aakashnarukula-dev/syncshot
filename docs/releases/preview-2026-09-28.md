# SyncShot preview — September 28, 2026

Downloadable builds with Google sign-in, Mac capture/rail fixes, and Android duplicate/empty-preview repairs. This is a preview, not a completed paid launch. Razorpay checkout does not charge or activate lifetime access; new accounts receive a three-day trial.

## Downloads

- **SyncShot-macOS-Apple-Silicon.zip** — Mac 0.2.21 for M-series Macs (arm64). Intel binaries are not included in this preview.
- **SyncShot-Android-2.0.11.apk** — signed Android 2.0.11 (version code 13), Android 8.0 or newer.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

## Mac installation

1. Download and unzip the Mac archive.
2. Quit any running SyncShot instance, then move SyncShot.app into Applications.
3. Open the app and follow macOS first-launch prompts. This build is ad-hoc signed and is not Apple-notarized.
4. Grant Screen Recording permission when requested, then restart SyncShot if macOS asks.
5. Sign in with Google. Use the same account on Android.

## Android installation and existing accounts

Open the APK on your phone and follow Android's installation prompts. Allow installation from your chosen browser or file manager only if you trust this repository.

**Existing installations:** this release uses a new release signing certificate. Android will reject an update if your installed copy uses a different certificate. Do not uninstall or clear app data to work around this until your existing account and unsynced images are secured. Updating an older differently signed installation without data loss requires its original signing key.

Existing phone-login users should link Google from account settings while still signed in. Signing into Google separately may create another account; accounts are not automatically merged.

## Fixes included

- Mac screenshot drag files survive upload completion; rail idle collapse and monitor transition races are handled.
- Google sign-in replaces new phone login on Mac and Android. Account access is verified by the server.
- Android retries reuse one image ID and resume incomplete uploads instead of creating duplicate tiles.
- Android deletes matching duplicate entries and prevents queued uploads from recreating deleted images.
- Android startup/refresh removes orphan gray preview rows whose cached image no longer exists.
